# Веб-чат: разбиение на компоненты

Документ описывает дерево компонентов пакета интерфейса чата и зону ответственности каждого компонента. Источники: `01-goals-and-context.md`, `02-requirements.md`, `03-architecture.md`, `04-open-questions.md`.

## Границы документа

- Охвачен весь интерфейс из `02-requirements.md`.
- Описаны имя, ответственность и состав компонента. Props, события и слоты не описываются: контракт между интерфейсом и движком остаётся отдельной темой (см. `04-open-questions.md`).
- Имена компонентов английские, PascalCase. Пояснения на русском.
- Все компоненты принадлежат **пакету интерфейса** (см. `03-architecture.md`, п. 7). Они только отображают полученные данные и сообщают о действиях пользователя наружу. Состояние живёт внутри экземпляра компонента, не в глобальных сторах.
- **Вне пакета:** элементы управления для съёмки (подстановка реплик, управление сценарием, «нет сети» и ошибка отправки по команде оператора). Их рисует движок чата в отдельном репозитории.

## Слои

1. **Базовые компоненты (`base`)** — мелкие переиспользуемые элементы без знания о чате.
2. **Компоненты сообщений (`message`)** — содержимое пузыря и всё, что связано с одним сообщением.
3. **Компоненты областей (`area`)** — части интерфейса: список чатов, диалог, шапка, ввод, окно информации, звонки.
4. **Корневой компонент (`ChatRoot`)** — собирает всё вместе, отвечает за раскладку под размер блока.

---

## 1. Корневой уровень

### ChatRoot

Точка входа пакета. Встраивается чат целиком.

- Корневой элемент экземпляра: на нём задаются CSS-переменные темы, он же является контейнером для `@container`, изолирует стили чата от страницы.
- Выбирает раскладку по размеру блока: если места мало — либо список чатов, либо диалог; если много — список рядом с диалогом.
- Принимает контекст открытия (например, открыть конкретный диалог) и режим «только чтение».
- Состоит из: `ChatSidebar`, `ChatView`, `CallLayer`, `MediaViewer`, `ChatInfo`, `ForwardDialog`.

---

## 2. Список чатов

### ChatSidebar

Левая часть интерфейса.

- Состоит из: `ChatSearch`, `ChatListTabs` (основной список / архив), `ChatList`.

### ChatList

Список чатов с закреплёнными вверху. Виртуализация не оговорена в требованиях, поэтому здесь не закладывается.

- Состоит из: `ChatListItem`.

### ChatListItem

Одна строка списка: аватар, название, последнее сообщение, время, счётчик непрочитанных, пометки закрепления и отключённого звука.

- Состоит из: `Avatar`, `Badge`, `MessageStatus`.

### ChatListTabs

Переключение между основным списком и архивом.

### ChatSearch

Поле глобального поиска и результаты: по сообщениям, пользователям и чатам.

- Состоит из: `SearchInput`, `SearchResultsList`, `SearchResultItem`.

---

## 3. Диалог

### ChatView

Правая часть интерфейса: один открытый чат любого типа (личный, «Избранное», группа, канал, чат поста канала, чат закреплённых сообщений, бот). Все они для интерфейса обычные чаты.

- Показывает состояния: пустой чат, загрузка, нет соединения.
- Показывает фон чата: картинку, адрес которой приходит в данных чата. Если её нет, фон задаёт тема.
- Состоит из: `ChatHeader`, `PinnedMessagesBar`, `ChatSearchBar`, `MessageList`, `ChatFooter`.

### ChatHeader

Шапка: аватар, название, статусная строка. Нажатие на имя или название открывает `ChatInfo`.

- Содержит кнопки: поиск внутри чата, аудио- и видеозвонок, меню.
- Состоит из: `Avatar`, `ChatStatusLine`, `IconButton`, `DropdownMenu`.

### ChatStatusLine

Строка под названием. Варианты по типу чата:

- пользователь: «онлайн» / «был в сети», «печатает…»;
- группа: количество участников, «3 пользователя печатают»;
- канал: количество участников;
- бот: пометка «Бот».

Если у чата задана подпись под названием (например, «Сохранённые сообщения» в «Избранном»), показывается она вместо статусной строки.

### PinnedMessagesBar

Полоса закреплённых сообщений вверху чата. Закреплённых может быть несколько: полоса показывает одно и позволяет переключаться между ними. Нажатие на сообщение переводит к нему. Кнопка в полосе открывает чат закреплённых сообщений (это обычный чат, интерфейс только сообщает о нажатии).

### ChatSearchBar

Поиск внутри чата: поле, счётчик результатов, переход к предыдущему и следующему.

### ChatFooter

Нижняя часть диалога. Показывает одно из: поле ввода, кнопку звука, «Присоединиться», «Открепить все сообщения», заглушку «только чтение», а при выделении сообщений панель выделения (`SelectionBar`).

- Что показывать, определяет одно поле в данных чата («нижняя панель»), а не тип чата и не признак подписки. Значение указывает тот, кто отдаёт данные.
- Состоит из: `MessageComposer`, `SelectionBar`, `ChannelMuteBar`, `JoinBar`, `UnpinAllBar`, `ReadOnlyNotice`.

### MessageComposer

Поле ввода сообщения.

- Черновик не хранит: сохранением недописанного текста при переключении между чатами занимается движок чата или приложение, в которое встроен чат. Как именно интерфейс передаёт им текст и получает его обратно, определит контракт.
- Содержит: поле ввода с форматированием и подсказкой упоминаний, кнопки эмодзи/стикеров, вложений, записи голоса и видеокружка.
- Показывает панель ответа или редактирования над полем.
- Состоит из: `ComposerInput`, `MentionSuggest`, `EmojiPicker`, `StickerPanel`, `AttachMenu`, `ComposerReplyPreview`, `IconButton`.

### ComposerInput

Многострочное поле ввода текста с форматированием.

### ComposerReplyPreview

Плашка над полем: цитируемое или редактируемое сообщение с кнопкой отмены.

### MentionSuggest

Подсказка участников при вводе `@`.

- Состоит из: `Avatar`.

### EmojiPicker

Панель выбора эмодзи.

### StickerPanel

Панель стикеров с наборами. Показывает также GIF и анимированные эмодзи, если они выбираются из панели.

### AttachMenu

Меню выбора типа вложения: картинка, видео, файл, геопозиция, контакт, опрос.

### SelectionBar

Панель действий при выделении нескольких сообщений: переслать, удалить, отменить выделение.

### ReadOnlyNotice

Заглушка вместо поля ввода, когда писать нельзя и других действий предложить нечего.

### ChannelMuteBar

Кнопка «Включить звук» / «Отключить звук» вместо поля ввода в канале, как в Телеграме. Надпись выбирается по признаку «звук отключён» у чата.

### JoinBar

Кнопка «Присоединиться» вместо поля ввода, например для неподписанного пользователя в канале. Нажатие сообщается наружу.

### UnpinAllBar

Кнопка «Открепить все сообщения» вместо поля ввода в чате закреплённых сообщений. Нажатие сообщается наружу.

## 4. Список сообщений

### MessageList

Прокручиваемая область с виртуализацией.

- Группирует сообщения по датам и по автору.
- Сообщает наружу о достижении верха (запрос ещё порции истории). Интерфейс не знает, сколько истории существует.
- Подсвечивает сообщение при переходе к нему (по цитате, ссылке, закреплению, поиску).
- Содержит кнопку «вниз» и переход к первому непрочитанному.
- Состоит из: `DateDivider`, `UnreadDivider`, `SystemMessage`, `MessageGroup`, `ScrollDownButton`.

### DateDivider

Разделитель по датам.

### UnreadDivider

Метка «Непрочитанные сообщения».

### SystemMessage

Системное сообщение («Иван добавлен в группу», «изменено название»).

### MessageGroup

Подряд идущие сообщения одного автора. Показывает аватар автора и имя в группе.

- Состоит из: `Avatar`, `MessageItem`.

### ScrollDownButton

Кнопка «вниз» со счётчиком непрочитанных.

- Состоит из: `Badge`.

### MessageItem

Одно сообщение целиком: пузырь, выделение, контекстное меню, реакции.

- Выбирает компонент содержимого по типу сообщения.
- Показывает режим выделения (флажок).
- Состоит из: `MessageBubble`, `MessageContextMenu`, `MessageReactions`, `CommentsButton`.

### MessageBubble

Пузырь сообщения. Раскладка внутри (например, время внутри или вне пузыря) задаётся пресетом, внутренние части вынесены в слоты и мелкие компоненты.

- Состоит из: `MessageForwardedLabel`, `MessageReplyQuote`, содержимого по типу (раздел 5), `MessageText`, `MessageMeta`.

### MessageMeta

Подвал пузыря: время, пометка «изменено», статус отправки/прочтения. Слева от времени показываются иконка булавки (если сообщение закреплено), а ещё левее иконка и счётчик просмотров (если счётчик задан), как у постов канала.

- Состоит из: `MessageStatus`, `Icon`.

### MessageStatus

Иконка статуса: отправлено, прочитано, ошибка отправки (с повторной отправкой).

### MessageForwardedLabel

Метка «Переслано от…».

### MessageReplyQuote

Цитата сообщения, на которое отвечают. Нажатие переводит к исходному сообщению.

### MessageText

Текст с форматированием, ссылками и упоминаниями. Текст можно выделить, чтобы ответить на выделенный фрагмент; тогда `MessageContextMenu` предлагает ответить на выделенное, и в цитате показываются именно эти слова.

- Состоит из: `LinkPreview`.

### LinkPreview

Превью ссылки.

### MessageContextMenu

Контекстное меню: ответить, переслать, отредактировать, удалить (у себя и у всех), закрепить, получить ссылку, выделить.

- Состоит из: `DropdownMenu`.

### MessageReactions

Реакции под сообщением и список поставивших реакцию.

- Состоит из: `ReactionChip`, `ReactionPicker`, `ReactionUsersList`.

### CommentsButton

Кнопка комментариев у сообщения, ведёт в чат поста.

- Показывается, только если у сообщения задано поле «комментарии». Если оно равно нулю, надпись «Прокомментировать», иначе «{количество} комментариев».
- Внешний вид выбирается по типу сообщения: полоса под пузырём или иконка рядом с сообщением (для сообщений без пузыря, например видеокружка).
- Состоит из: `Icon`.

## 5. Содержимое сообщений (по типам)

Каждый компонент отвечает за один тип содержимого и подставляется внутри `MessageBubble`.

| Компонент | Тип содержимого |
| --- | --- |
| `ContentImage` | Картинка (с подписью) |
| `ContentVideo` | Видео (с подписью) |
| `ContentAlbum` | Альбом из нескольких фото в одном сообщении |
| `ContentFile` | Файл, прогресс загрузки |
| `ContentAudio` | Аудиосообщение, выбор скорости |
| `ContentVideoNote` | Видеосообщение (кружок), выбор скорости |
| `ContentSticker` | Стикер |
| `ContentAnimation` | GIF и анимированные эмодзи |
| `ContentPoll` | Опрос, голосование, результаты |
| `ContentLocation` | Геопозиция |
| `ContentContact` | Контакт |
| `ContentCall` | Сообщение о звонке в истории («исходящий звонок 1:50», «входящий звонок» и т.п.) |

Текст выводится компонентом `MessageText` (раздел 4). Подпись к картинке или видео тоже использует `MessageText`.

Общие части:

- `UploadProgress` — прогресс загрузки и кнопка отмены (для файлов и медиа).
- `PlayerControls` — кнопка воспроизведения, полоса прогресса и выбор скорости (для аудио и видеосообщений).

## 6. Окно информации о чате

### ChatInfo

Информация о чате: участники, медиа, файлы, ссылки, блокировка пользователя.
Способ показа (боковая панель или модальное окно) не решён, см. раздел «Нерешённое».

- Состоит из: `ChatInfoHeader`, `ChatInfoTabs`, `ParticipantsList`, `SharedMediaGrid`, `SharedFilesList`, `SharedLinksList`, `BlockUserButton`.

### ChatInfoHeader

Аватар, название, статус, количество участников.

### ChatInfoTabs

Переключение между участниками, медиа, файлами, ссылками.

### ParticipantsList

Список участников.

- Состоит из: `Avatar`.

### SharedMediaGrid

Сетка картинок и видео чата. Нажатие открывает `MediaViewer`.

### SharedFilesList

Список файлов чата.

### SharedLinksList

Список ссылок чата.

### BlockUserButton

Кнопка блокировки пользователя.

## 7. Просмотрщик медиа

### MediaViewer

Полноэкранный просмотр картинок и видео. Переход между элементами, закрытие.

- Состоит из: `IconButton`.

## 8. Звонки (имитация)

**Отложено:** экраны звонка, мини-окно и демонстрация экрана. В первую очередь остаются только `ContentCall` (сообщение о звонке в истории, раздел 5) и кнопки звонка в `ChatHeader`. Описание ниже сохранено для будущей работы. Изображения собеседников берутся из данных, плитка самого пользователя показывает его камеру.

### CallLayer

Контейнер звонков. Показывает нужный экран и мини-окно.

- Состоит из: `CallScreen`, `CallMiniWindow`.

### CallScreen

Один экран звонка. Состояния:

1. входящий звонок;
2. исходящий звонок;
3. соединение;
4. звонок в процессе;
5. звонок завершён;
6. звонок отклонён / «нет ответа».

Поддерживает аудио- и видеозвонки, в том числе групповые.

- Состоит из: `CallParticipantsGrid`, `CallControls`, `Avatar`.

### CallParticipantsGrid

Раскладка участников звонка: один собеседник или несколько.

- Состоит из: `CallParticipantTile`.

### CallParticipantTile

Видео или аватар одного участника, статус микрофона.

### CallControls

Кнопки: принять, отклонить, микрофон, камера, демонстрация экрана, завершить, свернуть.

- Состоит из: `IconButton`.

### CallMiniWindow

Свёрнутый звонок: мини-окно поверх интерфейса, пока открыт чат.

## 10. Окно пересылки

### ForwardDialog

Окно выбора чата, в который пересылаются выбранные сообщения. Открывается из `MessageContextMenu` и `SelectionBar`. Саму пересылку выполняет движок чата или приложение, интерфейс только сообщает о выборе получателя.

- Состоит из: `Modal`, `SearchInput`, `ChatListItem`.

---

## Сводка по состояниям интерфейса

| Состояние | Где отображается |
| --- | --- |
| Пустой чат | `ChatView` через `EmptyState` |
| Загрузка | `ChatList`, `MessageList` через `Spinner` |
| Нет соединения | `ChatView` (плашка) |
| Ошибка отправки | `MessageStatus`, повторная отправка из `MessageContextMenu` |
| Режим «только чтение» | `ChatRoot` и `ChatFooter` |
| Управление с клавиатуры | сквозное требование ко всем интерактивным компонентам |

---

## Нерешённое

- Способ показа `ChatInfo`: боковая панель или модальное окно.
- Расположение элементов внутри `MessageBubble` (время внутри или вне пузыря) в требованиях считается сложным; в разбиении заложены только мелкие компоненты и слоты (`03-architecture.md`, часть 2, п. 5).
- Контракт между интерфейсом и движком: какие данные интерфейс получает и какие события отдаёт (`04-open-questions.md`).
- Состав настроек киноинтерфейса и панель оператора относятся к движку чата и в этот документ не входят.
